# Imágenes del tema: Conocimientos previos

Hay placeholders `.svg` listos. Sustitúyelos por tus fotos educativas usando el mismo nombre (puedes cambiar la extensión a `.jpg` o `.png` y actualizar la ruta en el HTML):

- `componentes-pc.svg` — vista general del hardware
- `cpu.svg` — procesador
- `ram.svg` — memoria RAM
- `placa-base.svg` — motherboard
- `gpu.svg` — tarjeta gráfica
- `almacenamiento.svg` — HDD o SSD
