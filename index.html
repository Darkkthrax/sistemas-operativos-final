Sistemas Operativos

Un sistema operativo es el software intermediario entre el usuario, las aplicaciones y el hardware. Administra recursos como el procesador, la memoria, el almacenamiento y los dispositivos, y ofrece un entorno seguro para ejecutar programas sin que el usuario deba controlar cada detalle del computador.

Explorar temas Ver conocimientos previos

¿Qué es un sistema operativo?

El sistema operativo oculta la complejidad del hardware y proporciona una plataforma común para las aplicaciones. Gracias a él podemos abrir programas, guardar archivos, usar la red o imprimir documentos sin escribir instrucciones de bajo nivel para cada componente.

También actúa como administrador de recursos: decide qué proceso usa la CPU, cuánta memoria recibe cada programa y cómo se comparten los dispositivos cuando varias tareas se ejecutan al mismo tiempo.
