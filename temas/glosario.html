Conceptos

Glosario

Definiciones cortas de los términos que atraviesan el curso, agrupadas en hardware, software, redes y seguridad.

En este glosario

  1. Hardware
  2. Software
  3. Redes
  4. Seguridad

Hardware

  • CPU: unidad central de procesamiento. Ejecuta las instrucciones de los programas; el sistema operativo reparte su tiempo entre procesos.
  • RAM: memoria de acceso aleatorio. Guarda, de forma volátil, el sistema y los programas en ejecución.
  • Placa base: tarjeta principal que conecta CPU, RAM, GPU, almacenamiento y puertos, y define la compatibilidad del equipo.
  • GPU: unidad de procesamiento gráfico. Calcula en paralelo imágenes y vídeo; puede ir integrada o como tarjeta dedicada con VRAM.
  • Almacenamiento: disco HDD o SSD que conserva el sistema, las aplicaciones y los archivos aunque el equipo esté apagado.
  • Caché: memoria pequeña y rápida, cerca del procesador, que guarda datos e instrucciones de uso reciente para evitar ir a la RAM o al disco.
  • Buffer: zona temporal en memoria que acumula datos entre dos partes de distinta velocidad, por ejemplo disco y aplicación.
  • MMU: unidad de manejo de memoria. Traduce direcciones virtuales a físicas e impide que un proceso escriba en la memoria de otro.

Software

  • Sistema operativo: software intermediario entre el usuario, las aplicaciones y el hardware. Administra recursos y ofrece un entorno seguro para ejecutar programas.
  • Programa: secuencia de instrucciones guardada en el almacenamiento. Es estático hasta que alguien lo ejecuta.
  • Proceso: instancia de un programa en ejecución: memoria, registros, archivos abiertos y un estado que el sistema puede cambiar.
  • Kernel: núcleo del sistema operativo. Es la capa más cercana al hardware y corre en modo privilegiado.
  • Virtualización: técnica con la que el sistema toma un recurso físico y lo presenta como una versión más general y fácil de compartir.
  • Llamada al sistema: pedido que hace un proceso para que el núcleo ejecute una operación privilegiada, como leer un archivo.
  • Shell: intérprete de comandos. Espera una orden, la ejecuta con los servicios del sistema y vuelve a mostrar el prompt.
  • Driver: software del sistema que traduce peticiones abstractas al lenguaje de un dispositivo concreto.
  • Sistema de archivos: esquema con el que el sistema organiza un volumen en archivos, carpetas, metadatos y permisos.
  • Planificador: componente que decide qué proceso listo usa la CPU y en qué orden, según una política como FCFS o SJF.
  • Sección crítica: tramo de código donde un proceso modifica un recurso compartido y solo uno debe estar dentro a la vez.
  • Condición de carrera: fallo que aparece cuando el resultado depende del orden en que varios procesos tocan el mismo recurso.
  • Semáforo: variable entera que cuenta unidades de un recurso. Se modifica con wait y signal para sincronizar procesos.
  • Deadlock: bloqueo mutuo: cada proceso retiene un recurso y espera otro que nadie suelta.

Redes

  • Sistema distribuido: conjunto de computadores autónomos conectados por la red que cooperan con mensajes y se presentan como un servicio único.
  • Cliente-servidor: arquitectura en la que el cliente pide un servicio y el servidor lo procesa, a menudo en capas de aplicación y base de datos.
  • IPC: comunicación entre procesos. En un sistema distribuido se hace con mensajes por la red, sin memoria compartida.
  • RPC: llamada a procedimiento remoto. Hace que una función en otra máquina se vea como una llamada local.
  • Socket: punto final de red identificado por dirección y puerto. TCP ofrece un flujo fiable; UDP envía datagramas sin garantía.
  • Middleware: capa que intermedia entre aplicaciones, bases de datos y redes sobre un sistema operativo de red.
  • Transparencia: capacidad de ocultar la separación de los nodos para que el usuario perciba el sistema como un todo.
  • DNS: servicio de nombres que traduce un nombre lógico, como un dominio, a una dirección de red.
  • Escalabilidad: capacidad de soportar más carga añadiendo instancias, balanceo, réplicas o colas asíncronas.
  • Failover: cambio automático al servidor de respaldo cuando cae el primario, para mantener el servicio.

Seguridad

  • Modo usuario y modo kernel: niveles de privilegio. En modo usuario un programa no llega directo a los dispositivos; en modo kernel el sistema sí puede.
  • Aislamiento: separación entre procesos y usuarios para que uno no dañe los datos ni los recursos de otro.
  • Permisos: reglas que dicen quién puede leer, escribir o ejecutar un archivo o directorio.
  • ACL: lista de control de acceso. Guarda, en cada recurso, permisos por usuario o por grupo.
  • Exclusión mutua: garantía de que solo un proceso entra a la vez en una sección crítica que toca un recurso compartido.
  • Autenticación: comprobación de la identidad de un usuario o un servicio antes de conceder acceso.
  • Arranque seguro: mecanismo del firmware que verifica la firma del software de arranque antes de cargarlo.
